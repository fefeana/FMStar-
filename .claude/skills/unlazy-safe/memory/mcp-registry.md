# دليل خوادم MCP (MCP Registry)

## قواعد الاستخدام العامة
- استدعِ خادم `MCP` عندما يضيف معلومة فعلية أو ينفّذ عملية لا تتوفر في السياق الحالي.
- تجنب الاستدعاءات المتكررة غير الضرورية لنفس المورد داخل نفس المهمة.
- عند تعذّر الاتصال أو انتهاء المهلة، وضّح ذلك ببساطة وقدّم بديلاً عملياً فوراً.

## الخوادم المسجلة
- أضف هنا كل خادم MCP متاح مع غرضه ومتى يُستخدم ومتى يُتجنب.
